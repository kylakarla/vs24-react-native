# Expo Furniture Shop App

See on React Native / Expo põhine mobiilirakendus, mis sisaldab tooteloendit, detailvaadet, lemmikute süsteemi, profiilivaadet ja navigeerimist tabide abil. Projekt kasutab **Expo Router**, **Context API** ja **React Hooks** funktsionaalsust.

---

## 📱 Funktsioonid

 Toodete nimekiri avalehel  
 Otsing toodete filtreerimiseks  
 Toote detailvaade (pilt, hind, kirjeldus)  
 Lemmikute lisamine ja eemaldamine (Favorites Context)  
 Lemmikute ekraan  
 Profiilivaade (kasutaja nimi + logout)  
 Tab navigatsioon (Home, Favorites, Profile)  
 State haldamine Context API-ga  
 Expo Router failistruktuur

---

## 📦 Kasutatud tehnoloogiad

- **Expo SDK**
- **React Native**
- **Expo Router**
- **React Context API**
- **TypeScript**
- **Ionicons**
- **Expo Go (testimiseks)**
